# Marz Rips

A responsive, single-page prototype for Marz Rips. The site runs as a static page and needs no build step or third-party libraries.

## Run it

Open `index.html` in a browser, or serve this folder with any static web server. GitHub Pages can serve the same page from the repository root.

## Prototype features

- Responsive desktop and mobile layouts, including mobile quick navigation.
- Four simulated rip tiers: Quick Rip ($3), Boost Rip ($5), Heat Rip ($9), and Marz Rip ($13).
- Animated placeholder reveals, local collection binder, collector XP and levels, daily visit streaks, achievements, and recent activity.
- $1/month membership preview, Hold My Cards preview, and a combined-shipping request preview.
- Progress is stored in browser local storage on the current device. Previous `marzrips` prototype data is migrated when the page loads.

## Prototype boundaries

Every rip is free and simulated. Pulls are fictional Marz-universe placeholders, not Pokémon cards. There is no account service, payment processing, physical inventory, shipment creation, or production membership checkout. Those integrations are intentionally left for the next phase.
